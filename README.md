# المصحف المعلم

تطبيق أندرويد للاستماع إلى القرآن الكريم وتكراره وحفظه، مع عرض صفحات مصحف المدينة النبوية من مجمع الملك فهد لطباعة المصحف الشريف. ويعمل أيضاً موقعاً في المتصفح.

## المزايا

- الاستماع بأصوات عدة قرّاء، مع تكرار الآية أو السورة، وتكرار الآيات للحفظ.
- سكوت بعد كل آية بمقدار ربع مدة الآية أو نصفها أو ثلاثة أرباعها أو مثلها، أو بدون سكوت (الافتراضي)، مع رمز في الشاشة العلوية يبيّن مقداره.
- مصحفان من مجمع الملك فهد:
  - مصحف المدينة طبعة 1421.
  - مصحف المدينة طبعة 1405، حروفه أعرض وأثقل وأرقام آياته أوضح.
- الضغط المطوّل على مفتاح «المصحف» يبدّل بين الطبعتين.
- تظليل الآية المقروءة وتقليب الصفحات مع التلاوة.
- المصحف يملأ الشاشة، مع خيار للرجوع إلى شكل الصفحة المطبوعة.
- تنزيل المصحفين والتلاوات للاستعمال بدون إنترنت.

## التثبيت على أندرويد

نزّل أحدث ملف `apk` من صفحة [الإصدارات](../../releases) وثبّته.

## تشغيله موقعاً على GitHub Pages

من إعدادات المستودع: **Settings** ثم **Pages**، اختر الفرع `main` والمجلد `/ (root)` ثم **Save**. بعد دقيقة يعمل على:
`https://اسم-حسابك.github.io/اسم-المستودع/`

في الموقع يعمل عرض المصحفين والاستماع والسكوت بعد كل آية، وتنزيل المصحفين للقراءة بدون إنترنت. أما التشغيل مع إطفاء الشاشة فخاص بتطبيق أندرويد.

## محتوى المستودع

| الملف أو المجلد | المحتوى |
|---|---|
| `index.html` | التطبيق كله: الواجهة والتشغيل والمصحف |
| `mushaf-data.js` | ترتيب صفحات مصحف طبعة 1421 وأسطرها |
| `mushaf-data1.js` | ترتيب صفحات مصحف طبعة 1405 وأسطرها |
| `fonts.js` و`f/` | خطوط الواجهة والبسملة |
| `names/` | أصوات أسماء السور |
| `prompts/` | أصوات التنبيهات |
| `version.js` | رقم الإصدار |
| `tools/build-mushaf-data.js` | يبني بيانات المصحف من مستودع [zonetecde/mushaf-layout](https://github.com/zonetecde/mushaf-layout) |
| `tools/build_apk_from_base.py` | يضع ملفات المستودع داخل ملف `apk` سابق |
| `tools/zipalign.py` | يحاذي ملف `apk` بعد توقيعه |

## بناء ملف التطبيق من نسخة سابقة

```bash
python3 tools/build_apk_from_base.py old.apk . unsigned.apk
jarsigner -sigalg SHA256withRSA -digestalg SHA-256 -keystore <مفتاحك>.jks unsigned.apk <alias>
python3 tools/zipalign.py unsigned.apk MushafMuallim.apk
```

لتغيير رقم الإصدار في ملف التطبيق مرّر ملف `AndroidManifest.xml` معدّلاً وسيطاً رابعاً.

**مفتاح التوقيع لا يوضع في المستودع أبداً.** احفظه عندك، فبدونه لا يمكن تحديث التطبيق فوق النسخ المثبّتة.
